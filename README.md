# Digital Forensics Lab

##  About

This repository contains practical experiments performed as part of the **Digital Forensics Laboratory**. It covers evidence acquisition, data recovery, network analysis, email forensics, mobile forensics, steganography detection, process analysis, and malware analysis.

## Experiments

| No. | Experiment | Tool |
|---|---|---|
| 1 | Evidence Acquisition | FTK Imager |
| 2 | Deleted/Damaged File Recovery | TestDisk |
| 3 | Network Packet Analysis | Wireshark |
| 4 | Email Header & Spoofing Analysis | MHA |
| 5 | Digital Evidence Investigation | Autopsy |
| 6 | Disk Image Analysis | Sleuth Kit |
| 7 | Android Data Extraction | AFLogical OSE |
| 8 | Hidden Data Detection | StegExpose |
| 9 | Suspicious Process Identification | Process Explorer |
| 10 | Malware Disassembly & Analysis | Ghidra |

##  Objectives

- Understand digital forensic investigation techniques.
- Acquire and preserve digital evidence.
- Recover deleted files and partitions.
- Analyze network and email evidence.
- Perform computer and mobile forensics.
- Detect hidden data and suspicious processes.
- Perform basic malware analysis and reverse engineering.
